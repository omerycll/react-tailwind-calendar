# React Tailwind Calendar - Demo

Bu klasör, `react-tailwind-calendar` paketinin demo uygulamasını içerir.

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Vercel'e Deploy

1. [Vercel](https://vercel.com) hesabı oluşturun
2. GitHub repository'nizi bağlayın
3. **Root directory** olarak `example` klasörünü seçin
4. Vercel otomatik olarak yapılandırmayı algılayacak:
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`
5. Deploy edin!

**Not:** Paket npm'den yükleneceği için ekstra yapılandırma gerekmez.
